## Why Use FireBase in Expo Go Project

<br>
<div style="display: inline_block" align="center">

<img alt="React-Native-Firebase" width="160" src="./src/assets/react-native-firebase.png">

</div>
<br>

Using ***FireBase*** in your project has provided several benefits, especially if you are developing ***mobile apps*** and need robust and scalable backend functionality.

With Firebase Authentication, it’s easy to implement a secure and reliable solution for authenticating users using methods like email/password and social logins. Firebase Realtime Database and Firestore allow you to store and sync data in real time, ideal for applications that require instant updates, such as chat and social networks. Firebase Storage provides a scalable and secure solution for storing and serving user-generated content, such as photos and videos. ### Bottom line... Integration with Expo is made easy by good documentation and community support, speeding up development and simplifying maintenance. It provides a set of integrated solutions that work well together, allowing developers to create a great user experience with less infrastructure to worry about. ## Prerequisites
